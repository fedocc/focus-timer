# Фокус 1.3

Нативное приложение для macOS 14 и новее, Apple Silicon.

Распакуйте весь архив и откройте `Установить_Фокус.command` рядом с `Фокус.app`.
Установщик закрывает старые копии обычной командой выхода, сохраняет предыдущую
установленную копию и устанавливает новую в `~/Applications/Фокус.app`.
Если есть активный или сохраненный незавершенный блок, установка останавливается:
дождитесь окончания таймера в старом приложении и повторите установку.
Права администратора и разрешение «Универсальный доступ» не нужны.
Установщик не сбрасывает системные разрешения.

В меню отметьте приложения, укажите минуты и нажмите «Начать».
Одна галочка разрешает приложение целиком: все существующие и новые окна,
а также его диалоги открытия и сохранения файлов. Поиск ищет по названию
приложения; скрытые фильтром галочки сохраняются.

Выбор и минуты сохраняются. Закрытое выбранное приложение остается в списке.
Во время блока его можно открыть кнопкой в меню или на экране защиты.
Перезапуск с новым PID не меняет разрешение: проверяются bundle ID и путь
приложения. Перемещенная или другая установленная копия требует нового выбора
перед следующим блоком. Запуск другой программы из разрешенного Finder
или другого выбранного приложения не разрешает ее автоматически.

В строке меню идет обратный отсчет. При переходе в невыбранное приложение
появляется экран защиты и «Фокус» возвращает к разрешенному приложению.
Если разрешенные приложения закрыты, таймер продолжает идти; их можно открыть
из меню защиты. Вкладки и адреса внутри выбранного браузера не ограничиваются.

Паузы, отмены, изменения разрешенных приложений и досрочного выхода нет.
Активный таймер восстанавливается после перезапуска. После окончания прозвучит
короткий сигнал и откроется меню. Следующий блок автоматически не начинается.

Версия 1.2 читает настройки 1.0–1.1: объединяет выбранные окна каждого приложения
в одну галочку, сохраняет минуты. При восстановлении старой сессии окна также
объединяются в приложения; ID сессии, длительность, идентификатор загрузки системы
и оба срока окончания остаются прежними. Формат новых сохранений — версия 2.

Настройки и активный таймер: `~/Library/Application Support/FocusMenu/settings.json`.
Обновление не удаляет и не сбрасывает этот файл. Пользовательские данные не входят
в архив. Приложение работает локально без сервера и сторонних библиотек.

«Фокус» препятствует обычным переключениям и обычному выходу. Это не системный
киоск: принудительное завершение средствами macOS остановит защиту до следующего
запуска. Привилегированная служба не устанавливается.

## Сборка и проверки

Нужны инструменты разработчика Apple с компилятором Swift.

```sh
python3 build.py --test
python3 build.py --ui-test
python3 build.py --integration-test
python3 build.py
osascript -l JavaScript Tools/InstallFocus.js self-test
osascript -l JavaScript Tools/InstallFocus.js event-loop-test
zsh -n Установить_Фокус.command
python3 Tools/Package.py
```

`--test` проверяет таймер, миграцию, сохранение, политику и обнаружение приложений.
`--ui-test` проверяет нативные размеры, поиск, сохранение галочек и запрет выхода
во время блока на отдельном тестовом состоянии. `--integration-test` запускает
две временные GUI-программы на живом Mac: новые окна, файловые диалоги,
блокировку отдельной программы, перезапуск с новым PID. Защищенный таймер при
этих проверках не запускается, рабочие настройки не меняются.

Сборка имеет локальную ad-hoc подпись и не заверена Apple для публичного
распространения. На другом Mac для первого запуска может понадобиться штатное
«Открыть» в настройках безопасности.
