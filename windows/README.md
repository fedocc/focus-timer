# Фокус Таймер для Windows

Для обычного 64-битного компьютера скачайте архив `win-x64`. Для компьютера
на Windows ARM — `win-arm64`. Распакуйте весь архив в отдельную папку.

Откройте `InstallFocus.exe`: приложение установится в
`%LOCALAPPDATA%\Programs\FocusTimer`, в меню «Пуск» появится «Фокус Таймер».
Права администратора не нужны. Также можно запускать `FocusTimer.exe` прямо
из распакованной папки. Дополнительно устанавливать .NET не требуется.

Значок находится в области уведомлений рядом с часами; иногда Windows прячет
его под стрелкой. Нажмите значок, отметьте приложения, выберите минуты
и нажмите «Начать». Одна галочка разрешает все окна выбранного `.exe`, включая
новые окна и диалоги открытия/сохранения файлов. Выбор, поиск и минуты сохраняются.

Во время блока другие программы закрывает экран фокуса. Попытка переключения
сворачивает запрещенное окно и возвращает к разрешенному. Если Windows не
разрешит автоматическое переключение, экран остается: нажмите на название
разрешенного приложения. Двойной щелчок по приложению в меню также открывает его.
Закрытие и повторный запуск разрешенного `.exe` не меняет разрешение.
Отдельная программа, открытая из разрешенного Проводника, остается запрещенной.

Паузы, отмены, изменения списка и обычного выхода до конца блока нет.
Закрытие меню прячет меню, а не останавливает таймер. При перезапуске приложения
сохраненный таймер восстанавливается. Установщик откажется обновлять приложение,
пока в сохранении есть незавершенный блок; сначала дождитесь его окончания.
Предыдущая установленная копия остается в соседней папке `FocusTimer.previous-*`.

Данные: `%LOCALAPPDATA%\FocusTimer\settings.json`.
Обновление сохраняет этот файл. Перенос настроек с Mac не предусмотрен.

Проверка выпуска выполняется на Windows Server 2025 в GitHub Actions:
таймер, сохранение, нативные формы, настоящие файловые диалоги, переключение
между двумя тестовыми приложениями и перезапуск с новым PID. ARM64-архив
собирается отдельно; проверка окон выполняется на x64. Ручная приемка на вашем
Windows 11 остается полезной, особенно для UWP-программ и нескольких мониторов.

Основная целевая система — Windows 11. .NET 10 также поддерживает отдельные
редакции Windows 10 LTSC/Enterprise; обычная Windows 10 после окончания поддержки
Microsoft отдельно не заявляется как проверенная платформа.

Приложение ограничивает обычные переключения. Диспетчер задач, защищенный
рабочий стол, выход из Windows и приложения с повышенными привилегиями могут
обходить обычное оконное управление. Оно не заменяет системный киоск.
Сайты и вкладки внутри разрешенного браузера не фильтруются.

Выпуск не подписан коммерческим сертификатом Windows. Не меняйте настройки
защиты системы ради установки; при сомнении проверьте SHA256 и исходники.
