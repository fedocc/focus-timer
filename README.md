# Фокус Таймер

Нативный таймер работы для **macOS** и **Windows**. Выберите приложения,
задайте время и начните блок. До окончания таймера доступны выбранные приложения
целиком: старые и новые окна, файловые диалоги, повторный запуск с новым PID.

Паузы, отмены и обычного досрочного выхода нет. Выбор и активный таймер сохраняются.
Работает локально, без сервера, аккаунта и сторонних библиотек в приложении.

## Скачать

Готовые приложения и контрольные суммы находятся в [Releases](https://github.com/fedocc/focus-timer/releases/latest).

- **Windows 11, обычный компьютер:** архив `FocusTimer-Windows-win-x64-1.3.0.zip`.
  Распакуйте целиком и откройте `InstallFocus.exe`. .NET включен в архив.
- **Windows на ARM:** архив `win-arm64`.
- **Mac:** архив `FocusMenu-macOS-1.3.zip`. Распакуйте целиком и откройте
  `Установить_Фокус.command`. Для macOS 14+, архитектура указана в заметках выпуска.

Установщики сохраняют настройки и предыдущую установленную копию. Они не
прерывают активный блок: обновление возможно после его окончания.

## Как пользоваться

На Mac значок находится в строке меню, на Windows — в области уведомлений.
Откройте меню, отметьте нужные приложения, укажите минуты и нажмите «Начать».
Поиск фильтрует названия, сохраняя скрытые галочки. В активном меню видны
обратный отсчет и разрешенные приложения.

Невыбранное приложение закрывает экран фокуса. Запуск другой программы из
разрешенного Finder или Проводника не добавляет ее в разрешенные.
Сайты и вкладки внутри выбранного браузера не фильтруются.

Подробности: [Windows](windows/README.md), [macOS](macos/README.md),
[проверки и ограничения](docs/testing.md).

## Разработка

**macOS:** Apple Swift, без внешних зависимостей.

```sh
cd macos
python3 build.py --test
python3 build.py --ui-test
python3 build.py --integration-test
python3 build.py
python3 Tools/Package.py
```

**Windows:** .NET 10 SDK, WinForms и Win32; сторонние NuGet-пакеты не используются.

```powershell
dotnet run --project windows/FocusTimer.CoreTests -c Release
dotnet run --project windows/FocusTimer.WindowsTests -c Release -- artifacts/windows-tests
./scripts/Publish-Windows.ps1 -Runtime win-x64
```

На Mac можно запускать тесты ядра и компилировать Windows-проект с
`EnableWindowsTargeting`. Выпускные `.exe` собираются на Windows через GitHub Actions.

Это помощник для фокуса, а не системный киоск. Принудительное завершение процесса
или выход из ОС остановят оконную защиту до следующего запуска. Настройки
пользователя, ключи, кеши и готовые тестовые программы в репозиторий не входят.
